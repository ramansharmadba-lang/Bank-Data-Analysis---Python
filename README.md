# Bank-Data-Analysis---Python
# 🏦 Bank Data Analysis Project

A Python data analysis project that cleans a messy banking dataset and explores customer, transaction, and loan patterns through exploratory data analysis (EDA) and visualization.

## 📋 Overview

This project takes a raw, messy banking dataset (`Banking_messy_data.csv`) and walks through a full data analysis pipeline:

1. **Data Understanding** — inspect structure, types, missing values, and duplicates
2. **Data Cleaning** — standardize inconsistent values, fix invalid entries, and handle outliers
3. **Exploratory Data Analysis (EDA)** — answer business questions about customers, accounts, and loans
4. **Visualization** — charts and plots to communicate key patterns

## 🗂️ Project Structure

```
.
├── Bank_Project.ipynb          # Main analysis notebook
├── Banking_messy_data.csv      # Raw input data (not included — see Data section)
├── Bank_Poject_Cleaned.csv     # Cleaned dataset (generated by the notebook)
└── README.md
```

## 🧹 Data Cleaning Steps

The raw dataset contains common real-world data quality issues, which are addressed as follows:

| Column | Issue | Fix |
|---|---|---|
| `Gender` | Inconsistent casing/labels (`M`, `male`, `F`, etc.) | Standardized to `Male` / `Female` / `Other` |
| `City` | Typos and inconsistent casing | Corrected misspellings (e.g. `Banglore` → `Bengaluru`) and title-cased |
| `Age` | Invalid values (negative, >100) | Coerced to numeric, invalid values replaced with the median |
| `TransactionDate`, `AccountOpenDate` | Mixed date formats, impossible dates | Parsed to datetime; transactions dated before account opening are nulled |
| `TransactionAmount` | Currency symbols, commas, negatives, outliers | Cleaned to numeric, converted to absolute value, capped at the 99th percentile |
| `AccountType` | Inconsistent casing | Standardized/title-cased |
| `Name`, `BranchManager` | Inconsistent casing | Title-cased |
| `CreditScore` | Out-of-range values (outside 300–900) | Coerced to numeric, invalid values set to null |
| Duplicate rows | Exact duplicate records | Dropped |

The cleaned dataset is exported to `Bank_Poject_Cleaned.csv` for use in the EDA and visualization phases.

## 📊 Exploratory Data Analysis

The notebook answers questions such as:

- What does the age distribution of customers look like?
- Which account type is the most common?
- What is the average transaction amount per account type?
- Which cities generate the highest total transaction volume?
- How does loan amount vary by loan status?
- Which bank approves the most loans?
- How does credit score relate to loan approval?

## 📈 Visualizations

The notebook generates the following charts using `matplotlib` and `seaborn`:

- **Bar chart** — number of accounts by account type
- **Line chart** — monthly transaction trend
- **Boxplot** — transaction amount distribution by account type
- **Heatmap** — correlation between age, transaction amount, loan amount, and credit score
- **Pie chart** — loan status distribution (Approved / Rejected / Not Approved)
- **Bar chart** — total transaction amount by bank

## 🚀 Usage

1. Clone this repository
2. Place your raw dataset as `Banking_messy_data.csv` in the project directory (update the file path in the notebook if needed)
3. Open and run the notebook:

```bash
jupyter notebook Bank_Project.ipynb
```

4. Run the cells in order — Data Understanding → Cleaning → EDA → Visualization. The cleaned dataset will be saved automatically as `Bank_Poject_Cleaned.csv`.

## 📝 Notes

- The raw data path in the notebook is currently a local Windows path and should be updated to a relative path (e.g. `./Banking_messy_data.csv`) before sharing or running on another machine.
- The dataset itself is not included in this repository; add your own CSV with matching column names (`CustomerID`, `Gender`, `City`, `Age`, `AccountType`, `TransactionDate`, `AccountOpenDate`, `TransactionAmount`, `LoanStatus`, `LoanAmount`, `Bank`, `CreditScore`, `Name`, `BranchManager`).
